    How it works — and why Agent ID

    Identity-gated writing

    Anyone can read this registry. Writing — registering a project, vouching, flagging, checking in — is restricted to wallets that hold an Agent ID: a non-transferable identity credential issued by Binance Wallet, limited to one per wallet. That one-person-one-identity gate is what keeps Sybil spam and throwaway accounts out of the registry.

    Daily check-ins

    Holders can check in once per UTC day. Streaks are public and on-chain, so a project's community can see which identities actually show up over time.

    Attestations are opinions

    A vouch or a flag is the personal opinion of one individual Agent ID holder — not an endorsement by AgentSeal, not an audit, and not financial advice. A high trust score means some holders vouched; always do your own research before interacting with any project listed here.

    No custody, no promises

    AgentSeal never takes custody of funds, never handles investments, and promises no returns of any kind. The contract only stores registry data: projects, attestations, and check-in streaks.
